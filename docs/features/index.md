# Features

Notebook Automation provides a comprehensive suite of features designed to transform educational content into intelligent, searchable knowledge bases.

## Core Features

### 🤖 [AI-Powered Processing](ai-processing.md)

Leverage advanced AI models to automatically generate summaries, questions, and insights from your educational content.

- **Intelligent Summarization** - OpenAI and Azure AI integration for content analysis
- **Question Generation** - Automatically create study questions from any content
- **Vocabulary Extraction** - Identify and define key terms and concepts
- **Multi-Model Support** - Flexible AI provider configuration

### 🗂️ [Obsidian Integration](obsidian-integration.md)

Seamlessly integrate with Obsidian for a powerful knowledge management workflow.

- **Hierarchical Course Structure** - Organize content by programs, courses, and modules
- **Rich YAML Frontmatter** - Comprehensive metadata for searchability
- **Contextual Menu Automation** - Process files directly from Obsidian
- **Document Placeholders** - Location-agnostic content references
- **Automated Index Generation** - Navigate complex course structures easily

### ☁️ [OneDrive Synchronization](onedrive-sync.md)

Integrate with Microsoft OneDrive for cloud storage and collaboration.

- **Bidirectional Sync** - Maintain folder structures between vault and cloud
- **Shared Links Management** - Generate shareable links for collaboration
- **Automatic Path Resolution** - Intelligent file location across environments
- **Cross-Platform Compatibility** - Works on Windows, macOS, and Linux

### 📚 [Anki Integration](anki-integration.md)

Export flashcards for spaced repetition learning using Anki.

- **Automated Flashcard Generation** - Convert Q&A to Anki format
- **Vocabulary Cards** - Export definitions and terms
- **Custom Deck Organization** - Organize by course or topic
- **Rich Card Formatting** - Preserve markdown and images

### 📄 [Multi-Format Processing](multi-format-processing.md)

Process various file formats into structured markdown notes.

- **PDF Documents** - Extract text, annotations, and images
- **Video Files** - Transcription and timestamp extraction
- **HTML Content** - Convert web pages to markdown
- **EPUB & Text** - Support for e-books and plain text

### 🔄 [Batch Operations](batch-operations.md)

Efficiently process large collections of educational content.

- **Parallel Processing** - Multi-threaded batch operations
- **Progress Tracking** - Real-time status updates
- **Error Recovery** - Retry failed operations
- **Incremental Updates** - Process only changed content

## Advanced Features

### 📊 [Metadata Extraction](metadata-extraction.md)

Automatically extract and organize comprehensive metadata from your content.

- **Course Hierarchy Detection** - Identify programs, courses, modules
- **Tag Generation** - Hierarchical and flat tag structures
- **Custom Properties** - Extensible metadata schema
- **Cross-Referencing** - Automatic linking between related content

### 🏗️ [Location-Agnostic Design](location-agnostic-design.md)

Work seamlessly across different computers and environments.

- **Relative Path References** - Content remains portable
- **Environment Configuration** - Device-specific absolute paths
- **Team Collaboration** - Share placeholders without conflicts
- **Multi-Platform Support** - Identical experience on any OS

### 🎥 [Video Transcript Consolidation](video-transcript-consolidation.md)

Combine lesson transcripts into comprehensive class-level notes.

- **Automatic Merging** - Consolidate multiple transcripts
- **Friendly Headings** - Generate section titles
- **Recursive Processing** - Handle nested course structures
- **Metadata Preservation** - Maintain all source information

### 🔧 [Extensible Architecture](extensible-architecture.md)

Customize and extend the system for your specific needs.

- **Plugin System** - Custom processors and resolvers
- **Template Customization** - User-defined note formats
- **Configuration Flexibility** - Adapt to any workflow
- **API Access** - Programmatic integration
