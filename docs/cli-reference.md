## Global Options

These options work with any command:

### --config, -c

Specify a custom configuration file path.

**Example:**
```bash
na video-notes -p "video.mp4" --config "custom-config.json"
```

### --debug, -d

Enable debug output for detailed troubleshooting information.

**Example:**
```bash
na pdf-notes -p "document.pdf" --debug
```

### --verbose, -v

Enable verbose output to see detailed progress information.

**Example:**
```bash
na vault generate-index "vault/" --verbose
```

### --dry-run

Simulate actions without making any actual changes. Useful for previewing operations.

**Example:**
```bash
na video-notes -p "videos/" --dry-run
```

### --help, -h

Show help information for the command.

**Example:**
```bash
na --help
na video-notes --help
na config --help
```

### --version

Show version information.

**Example:**
```bash
na --version
```

## video-notes Command

Process video files to extract transcripts, generate AI summaries, and create structured markdown notes.

### Syntax

```bash
na video-notes -p <path> [options]
```

### Arguments

- `-p, --path <path>` **(REQUIRED)** - Path to video file or directory containing videos

### Options

#### Output Options

- `-o, --overwrite-output-dir <path>` - Override the default output directory (normally uses vault root from config)
- `--override-vault-root <path>` - Specify explicit vault root path (overrides config)
- `--onedrive-fullpath-root <path>` - Override OneDrive fullpath root directory

#### Processing Options

- `--no-summary` - Skip AI summary generation (summary generated by default)
- `--force` - Overwrite existing notes even if they already exist
- `--retry-failed` - Retry only files that failed in previous run
- `--timeout <seconds>` - Set API request timeout in seconds

#### Authentication Options

- `--refresh-auth` - Force refresh Microsoft Graph API authentication
- `--no-share-links` - Skip OneDrive share link creation (links created by default)

### Examples

**Process single video:**
```bash
na video-notes -p "lecture-01.mp4"
```

**Process directory of videos:**
```bash
na video-notes -p "course/lectures/" --verbose
```

**Process without AI summaries:**
```bash
na video-notes -p "recordings/" --no-summary
```

**Retry failed videos:**
```bash
na video-notes -p "videos/" --retry-failed
```

**Force reprocess existing notes:**
```bash
na video-notes -p "video.mp4" --force
```

### Common Use Cases

**Course lecture processing:**
```bash
na video-notes -p "MBA/Operations/lectures/" --verbose
```

**Quick processing without OneDrive links:**
```bash
na video-notes -p "video.mp4" --no-share-links
```

**Preview operations:**
```bash
na video-notes -p "videos/" --dry-run --verbose
```

## pdf-notes Command

Process PDF files to extract text, annotations, generate AI summaries, and create structured markdown notes.

### Syntax

```bash
na pdf-notes -p <path> [options]
```

### Arguments

- `-p, --path <path>` **(REQUIRED)** - Path to PDF file or directory containing PDFs

### Options

#### Output Options

- `-o, --overwrite-output-dir <path>` - Override the default output directory
- `--override-vault-root <path>` - Specify explicit vault root path
- `--onedrive-fullpath-root <path>` - Override OneDrive fullpath root directory

#### Processing Options

- `--extract-images` - Extract images from PDFs and include in generated files
- `--no-summary` - Skip AI summary generation
- `--force` - Overwrite existing notes
- `--retry-failed` - Retry only failed files from previous run
- `--timeout <seconds>` - Set API request timeout

#### Authentication Options

- `--refresh-auth` - Force refresh Microsoft Graph API authentication
- `--no-share-links` - Skip OneDrive share link creation

### Examples

**Process single PDF:**
```bash
na pdf-notes -p "textbook-chapter-1.pdf"
```

**Process directory with image extraction:**
```bash
na pdf-notes -p "course/readings/" --extract-images
```

**Process without summaries:**
```bash
na pdf-notes -p "documents/" --no-summary --verbose
```

**Retry failed PDFs:**
```bash
na pdf-notes -p "pdfs/" --retry-failed
```

### Common Use Cases

**Academic paper processing:**
```bash
na pdf-notes -p "research/papers/" --extract-images --verbose
```

**Textbook chapter processing:**
```bash
na pdf-notes -p "textbooks/" --force
```

**Quick annotation extraction:**
```bash
na pdf-notes -p "annotated-notes.pdf" --no-share-links
```

## generate-markdown Command

Generate markdown files from HTML, TXT, and EPUB sources.

### Syntax

```bash
na generate-markdown -p <path> [options]
```

### Arguments

- `-p, --path <path>` - Relative path within vault/OneDrive structure for processing

### Options

- `--override-vault-root <path>` - Specify explicit vault root path
- `--extract-from-markdown` - Extract HTML content from OneDrive path in markdown frontmatter
- `--no-share-links` - Disable OneDrive share link generation

### Examples

**Convert HTML to markdown:**
```bash
na generate-markdown -p "articles/web-content.html"
```

**Convert EPUB book:**
```bash
na generate-markdown -p "books/textbook.epub"
```

**Batch convert files:**
```bash
na generate-markdown -p "documents/" --verbose
```

**Extract from frontmatter:**
```bash
na generate-markdown -p "notes/" --extract-from-markdown
```

### Common Use Cases

**Web article archiving:**
```bash
na generate-markdown -p "saved-articles/"
```

**eBook conversion:**
```bash
na generate-markdown -p "ebooks/course-materials.epub"
```

## vault Command

- [clean-index](#vault-clean-index) - Delete index files
- [vault-sync](#vault-vault-sync) - Synchronize with OneDrive

---

### vault generate-index

Generate index files for each directory in the vault.

**Syntax:**
```bash
na vault generate-index <path> [options]
```

**Arguments:**
- `<path>` - Path to vault directory (optional, defaults to vault root from config)

**Options:**
- `--override-vault-root` - Use provided path as vault root
- `--type <types>` - Filter by template types (main, program, course, class, module, lesson)
- `--force` - Force overwrite existing index files
- `--recursive` - Process subdirectories recursively

**Examples:**

Generate index for specific directory:
```bash
na vault generate-index "vault/projects"
```

Generate recursively with type filter:
```bash
na vault generate-index "vault/courses" --recursive --type course class
```

Force regenerate all indexes:
```bash
na vault generate-index "vault/" --recursive --force
```

**Common Use Cases:**
- Creating navigation structure in Obsidian
- Updating indexes after content changes
- Building course/project hierarchies

---

### vault ensure-metadata

Ensure metadata consistency across markdown files based on directory hierarchy.

**Syntax:**
```bash
na vault ensure-metadata <path>
```

**Arguments:**
- `<path>` - Path to vault directory

**Examples:**
```bash
na vault ensure-metadata "vault/projects" --verbose
```

**Common Use Cases:**
- Fixing missing or inconsistent metadata
- Propagating hierarchy information
- Maintaining vault organization

---

### vault clean-index

Delete all index markdown files in the vault.

**Syntax:**
```bash
na vault clean-index <path>
```

**Arguments:**
- `<path>` - Path to vault directory

**Examples:**
```bash
na vault clean-index "vault/" --dry-run
na vault clean-index "vault/projects"
```

**Warning:** This deletes files. Use `--dry-run` first to preview.

---

### vault vault-sync

Synchronize directory structure between OneDrive and vault (bidirectional by default).

**Syntax:**
```bash
na vault vault-sync <vault-path>
```

**Arguments:**
- `<vault-path>` - Path to vault directory

**Examples:**

Basic sync:
```bash
na vault vault-sync "C:\MyVault"
```

Preview sync operations:
```bash
na vault vault-sync "vault/" --dry-run --verbose
```

**Common Use Cases:**
- Creating document placeholders for OneDrive files
- Maintaining consistent structure across devices
- Setting up vault-OneDrive integration

**How It Works:**
- Scans OneDrive folder structure
- Creates corresponding folders in vault
- Generates document placeholder markdown files
- Preserves relative paths for portability

### config update

Update a configuration key with a new value.

**Syntax:**
```bash
na config update <key> <value>
```

**Arguments:**
- `<key>` - Configuration key to update
- `<value>` - New value

**Examples:**

Update AI provider:
```bash
na config update "AIService.Provider" "OpenAI"
```

Update vault path:
```bash
na config update "Paths.NotebookVaultFullpathRoot" "C:\MyVault"
```

Update OneDrive path:
```bash
na config update "Paths.OnedriveFullpathRoot" "C:\Users\Name\OneDrive"
```

**Common Keys:**
- `AIService.Provider` - AI service provider (OpenAI, Azure, Foundry)
- `AIService.Model` - AI model name
- `Paths.NotebookVaultFullpathRoot` - Vault root directory
- `Paths.OnedriveFullpathRoot` - OneDrive root directory

Use `na config list-keys` to see all available keys.

## refresh-token Command

Refresh OneDrive authentication token for Microsoft Graph API access.

**Syntax:**
```bash
na refresh-token
```

**Description:**

This command authenticates with Microsoft OneDrive and refreshes the authentication token. It opens a browser window for user authentication and stores the refresh token securely.

**When to Use:**
- Initial OneDrive setup
- After authentication token expires
- When encountering OneDrive authentication errors
- Before using OneDrive-dependent features

**Example:**
```bash
na refresh-token
```

**What Happens:**
1. Opens browser for Microsoft authentication
2. User signs in with Microsoft account
3. Token is stored securely
4. Can now use OneDrive features (vault-sync, share links, etc.)

**Troubleshooting:**

If you encounter authentication errors:
1. Run `na refresh-token` to reauthenticate
2. Ensure you have proper OneDrive permissions
3. Check that your Microsoft account is valid
4. Verify network connectivity

## Configuration Files

### Default Locations

The CLI searches for configuration files in this order:
1. Path specified by `--config` flag
2. `config/config.json` in executable directory
3. Current working directory

### Configuration Format

## Tips and Best Practices

### Command Discovery

Use `--help` extensively to discover options:
```bash
na --help                    # All commands
na video-notes --help        # Video-specific options
na tag --help                # Tag subcommands
```

### Dry Run First

Always use `--dry-run` for batch operations:
```bash
na video-notes -p "large-directory/" --dry-run --verbose
```

### Verbose for Troubleshooting

Enable verbose output when things don't work as expected:
```bash
na pdf-notes -p "document.pdf" --verbose
```

### Debug for Detailed Errors

Use debug mode for detailed error information:
```bash
na video-notes -p "video.mp4" --debug
```

### Config Management

View configuration before making changes:
```bash
na config view                              # See current settings
na config list-keys                         # See available keys
na config update "key" "value"              # Update specific key
```

### Batch Processing

Both video-notes and pdf-notes handle directories automatically:
```bash
na video-notes -p "lectures/"               # Processes all videos
na pdf-notes -p "readings/"                 # Processes all PDFs
```

### OneDrive Integration

Set up OneDrive once:
```bash
na refresh-token                            # Authenticate
na vault vault-sync "vault/"                # Sync structure
```

## Common Workflows

### Process Course Content

```bash
# 1. Authenticate with OneDrive
na refresh-token

# 2. Sync vault structure
na vault vault-sync "vault/courses"

# 3. Process videos
na video-notes -p "vault/courses/lectures/" --verbose

# 4. Process PDFs
na pdf-notes -p "vault/courses/readings/" --extract-images

# 5. Generate indexes
na vault generate-index "vault/courses" --recursive

# 6. Check metadata consistency
na vault ensure-metadata "vault/courses"
```

### Organize Existing Vault

```bash
# 1. Add nested tags based on hierarchy
na tag add-nested "vault/" --verbose

# 2. Consolidate duplicate tags
na tag consolidate "vault/"

# 3. Generate fresh indexes
na vault generate-index "vault/" --recursive --force

# 4. Ensure metadata consistency
na vault ensure-metadata "vault/"
```

### Convert Web Content

```bash
# 1. Convert HTML articles
na generate-markdown -p "articles/"

# 2. Convert ebooks
na generate-markdown -p "books/textbook.epub"

# 3. Generate summary notes
na pdf-notes -p "articles/" --verbose
```

### Authentication Issues

Refresh OneDrive token:

Use debug mode for detailed errors:
```bash

```
