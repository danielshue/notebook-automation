# Introduction to Notebook Automation

Welcome to Notebook Automation - a powerful tool for transforming educational content into organized, searchable notes.

## What is Notebook Automation?

Notebook Automation processes various types of educational materials (videos, PDFs, HTML) and converts them into structured markdown notes with AI-generated summaries, metadata, and cross-references.

## Key Features

- **Multi-Format Processing**: Handle videos, PDFs, HTML, and EPUB files
- **AI-Powered Summaries**: Generate intelligent summaries with OpenAI, Azure, or Anthropic
- **Obsidian Integration**: Create notes optimized for Obsidian vaults
- **OneDrive Sync**: Synchronize vault structure with OneDrive
- **Batch Processing**: Efficiently process large collections of files
- **Cross-Platform**: Works on Windows, macOS, and Linux

## Getting Started

1. **Install**: Download the CLI for your platform
2. **Configure**: Set up your AI service API key
3. **Process**: Start transforming your content

For detailed setup instructions, see [Quick Start](getting-started/quick-start.md).

## Use Cases

- **Students**: Organize course materials and lectures
- **Researchers**: Build literature review libraries
- **Educators**: Prepare teaching materials
- **Lifelong Learners**: Manage personal learning resources
