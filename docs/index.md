## 🌟 What is Notebook Automation?

**Notebook Automation** is a comprehensive toolkit that transforms educational content into intelligent, searchable knowledge bases. Whether you're a student managing course materials, an educator preparing teaching resources, or a researcher organizing papers, Notebook Automation automates the tedious tasks of content organization, metadata extraction, and knowledge enhancement.

### Why Notebook Automation?

**The Problem**: Educational content management is time-consuming. Materials are scattered across platforms, manually organizing takes hours, and extracting insights from lengthy documents is challenging.

**The Solution**: Intelligent automation that processes PDFs, videos, and documents into structured markdown notes with AI-powered summaries, questions, and cross-references—seamlessly integrated with your favorite tools.

### Key Capabilities

- **🤖 AI-Powered Processing** - Generate summaries, questions, and vocabulary from any content
- **📄 Multi-Format Support** - Process PDFs, videos, HTML, EPUB, and text files
- **🗂️ Obsidian Integration** - Native vault integration with hierarchical structures
- **☁️ OneDrive Sync** - Bidirectional synchronization and shared links
- **📚 Anki Export** - Flashcards for spaced repetition learning
- **🔄 Batch Operations** - Efficient processing of large content collections
- **🏗️ Location-Agnostic** - Works consistently across devices and platforms

## 🚀 Quick Start

Get up and running in 5 minutes:

1. **[Download](download.md)** the latest release for your platform
2. **[Install](getting-started/installation.md)** and verify the CLI
3. **[Configure](configuration/index.md)** AI services (optional but recommended)
4. **[Process](getting-started/quick-start.md)** your first document

```bash
# Process a PDF with AI summary
na pdf-notes -p "path/to/document.pdf"

# Process videos with transcription
na video-notes -p "path/to/videos/"

# Sync vault with OneDrive
na vault vault-sync "path/to/vault"
```

See the [Quick Start Guide](getting-started/quick-start.md) for detailed instructions.
